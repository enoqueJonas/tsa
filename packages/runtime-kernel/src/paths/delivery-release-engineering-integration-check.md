# Release Engineering integration check

Before merging this module, confirm the curriculum still tells one coherent story:

- Software Delivery Foundations defines build/release/run and promotion concepts.
- Automation and Shell makes workflows repeatable.
- Containers gives Steward a reproducible runtime artifact.
- CI verifies source and builds evidence/artifacts.
- CD deploys and introduces rollback/deployment strategies.
- Configuration Management makes target infrastructure reproducible.
- Nexus provides durable internal artifact distribution and provenance evidence.
- Release Engineering turns those capabilities into candidate, approval, deployment, verification and recovery decisions.
- The Delivery Engineer milestone integrates all of them.
