# Release Engineering assessment guide

Assessment should prioritize demonstration over terminology recall.

A strong learner can:

- trace a candidate to source and immutable repository artifacts;
- explain why promotion does not rebuild;
- justify automated versus human gates;
- show the running image digest after deployment;
- verify a meaningful Steward domain path;
- reason about rollback under schema change;
- execute a controlled failure using pre-defined criteria;
- improve a runbook based on what the exercise exposed.

A learner who can define 'release candidate' but cannot prove which artifact is running has not yet met the module outcome.
