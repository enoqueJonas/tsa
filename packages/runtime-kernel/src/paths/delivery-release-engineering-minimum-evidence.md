# Minimum release evidence set

A compact passing release package should contain or reference:

- candidate record;
- source commit and CI run;
- Nexus package/image immutable identities;
- migration/configuration note;
- gate/approval evidence;
- deployment execution ID;
- observed runtime artifact identity;
- health result;
- representative Steward behavior result;
- failure/recovery evidence from the lab;
- current runbook.

Anything beyond this should exist because it answers a real review or operational question, not because more screenshots look more complete.
