# Definition of done

Release Engineering is done when the curriculum and lab make these claims demonstrable rather than aspirational:

- candidates are immutable and identifiable;
- promotion does not rebuild;
- gates are meaningful;
- deployment evidence names the actual artifact;
- runtime behavior is verified;
- failed releases produce explicit decisions;
- rollback limitations are understood;
- runbooks are executable and reviewable;
- the process can be handed to another engineer.

The final Delivery Engineer milestone is responsible for proving the whole school works as one system.
