# Suggested review flow

1. Ask learner to name the currently selected candidate without opening the deployment target.
2. Trace candidate to source/CI/Nexus evidence.
3. Ask why each gate exists.
4. Deploy/promote using the documented entry point.
5. Independently inspect running artifact identity.
6. Execute representative Steward verification.
7. Trigger the controlled failure scenario.
8. Observe whether the learner follows pre-defined recovery criteria.
9. Verify the recovered state independently.
10. Hand the runbook to another person/context and identify hidden assumptions.

This keeps review focused on engineering evidence instead of presentation quality alone.
