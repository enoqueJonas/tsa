# Release Engineering completion criteria

The module is complete when the learner can demonstrate all of the following with Steward:

- identify an immutable release candidate;
- prove the candidate maps to reviewed source and CI evidence;
- promote without rebuilding application artifacts;
- explain why each release gate exists;
- deploy through the established automated path;
- prove the intended artifact is actually running;
- verify representative application behavior;
- detect a controlled failed release;
- follow pre-defined rollback or recovery criteria;
- restore and verify an acceptable state;
- hand the release procedure to another engineer through a versioned runbook and release record.
