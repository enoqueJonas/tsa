# Release Engineering reading map

Primary references used by the module:

- Semantic Versioning — release/version contract vocabulary.
- Twelve-Factor App: Build, release, run — separation of build, release and runtime configuration.
- Google SRE Book: Release Engineering — reproducibility, automation and release discipline.
- GitHub Releases documentation — practical release-record/repository concepts.
- DORA — delivery performance context and change-oriented operational thinking.

The curriculum does not require learners to reproduce these sources. They are used to extend and challenge the authored lesson material.
