# Release Engineering prerequisites

The learner should enter this module with working evidence from earlier Delivery Engineer modules:

- source-control and release-versioning fundamentals;
- repeatable shell/task automation;
- a containerized Steward API;
- CI verification and image building;
- automated deployment and rollback concepts;
- configuration-managed target infrastructure;
- Nexus-backed package/image distribution.

If one of these is missing, repair the earlier capability rather than simulating it with placeholder screenshots for Release Engineering.
