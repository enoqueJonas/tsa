# Gate design exercise

For each proposed gate, fill in:

| Proposed gate | Risk question | Evidence | Automated or human? | Failure action |
| --- | --- | --- | --- | --- |
| Example: required tests | Does this candidate satisfy the technical verification suite? | CI status tied to candidate | automated | reject candidate |

Delete any gate for which you cannot state a meaningful risk question.

If a human gate remains, explain what contextual judgment the human contributes that deterministic automation cannot reliably make.
