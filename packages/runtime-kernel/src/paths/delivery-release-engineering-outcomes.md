# Release Engineering learning outcomes

After completing the module, the learner should be able to:

1. construct an immutable release-candidate identity from source and artifact evidence;
2. design promotion gates around explicit risk questions;
3. preserve build-once/promote-the-same-artifact behavior;
4. distinguish deployment execution from verified runtime success;
5. collect concise release and runtime evidence;
6. reason about rollback versus forward recovery under persistent-state change;
7. preserve a last-known-good recovery path;
8. author and exercise a release runbook;
9. execute and review a controlled Steward release;
10. identify the remaining reliability/security concerns without prematurely solving later schools.
