# Later-school boundaries

## Quality Steward
Release Engineering consumes automated checks as gate evidence. Quality Steward later deepens test strategy, test architecture, reusable test infrastructure and confidence design.

## Security Steward
Release Engineering records artifact identity, provenance and approval. Security Steward later deepens signing, key management, secret management, vulnerability policy and supply-chain enforcement.

## Reliability Engineer
Release Engineering performs enough post-deploy observation to decide whether a release succeeded. Reliability Engineer later adds continuous metrics, logs, traces, SLOs, alerting, incident response and recovery engineering.

Do not duplicate those schools inside Delivery Engineer.
