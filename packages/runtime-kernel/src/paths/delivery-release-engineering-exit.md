# Release Engineering exit question

Before leaving this module, the learner should be able to answer:

> If the person who built Steward's delivery platform were unavailable, could I take one reviewed source revision, identify the exact candidate produced from it, decide whether it is promotable, deploy the already-approved artifact, prove what is actually running, detect an unacceptable release and recover using documented evidence rather than personal memory?

A 'no' identifies work to carry into the Delivery Engineer milestone.
