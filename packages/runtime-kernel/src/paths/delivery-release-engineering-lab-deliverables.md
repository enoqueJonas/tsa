# Steward release lab deliverables

The learner should finish with:

1. one immutable candidate record;
2. gate/risk-question matrix;
3. versioned release runbook;
4. successful promotion/deployment evidence;
5. running artifact identity proof;
6. health and representative domain verification;
7. complete release record;
8. controlled failed-release evidence;
9. rollback/forward-recovery execution evidence;
10. final verified-state evidence;
11. any runbook correction discovered during execution;
12. short handoff identifying what remains for Reliability/Security and the Delivery milestone.
