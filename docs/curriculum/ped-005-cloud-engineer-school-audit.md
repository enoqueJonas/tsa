## First remediation checkpoint: Kubernetes foundations

**Evidence from actual authored reading:** `cloud-kubernetes-foundations-worked.ts` supplies targeted new sections for all sixteen existing concept lessons, not a generic appendix. It establishes vocabulary and boundaries before commands, an isolated `kind-tsa-ped005` context, a complete two-replica nonproduction Deployment, readiness/resource declarations, a controlled Pod-replacement observation, a separately declared Service with selected endpoints and a deliberately empty-selector Service. It explains why the Nginx image tag is not an approved immutable Steward artifact and why reconciliation does not imply application health or genuine node-failure high availability.

**Source validator (expanded to all sixteen concept lessons):** `scripts/check-cloud-k8s-lesson-source.mjs` extracts the exact published YAML, parses it using Python/PyYAML, checks Deployment selector-to-template labels, readiness, resources, replica count, healthy/empty Service selectors, intentionally unschedulable Pod, unbound PVC, deliberately failing readiness probe, namespaced RBAC allow-only rules and an illustrative OpenShift Route. It does not execute any cluster. This checks a teaching fixture and its wiring, **not a running Kubernetes cluster**.

**Wrapper correction:** the Cloud entrypoint no longer inserts a shallow generated path orientation and preparation activities before each real Kubernetes reading/practical. `scripts/check-resolved-practical-contracts.mjs` requires the 16 original teaching readings + milestone, their corresponding original practical and transfer reflection, without treating wrappers as substantive evidence.

**Required next steps:** validate the rendered lesson sequence and execute the safe kind labs, then verify true OpenShift-only behavior in an authorized disposable cluster, and complete the eleven-path Cloud school audit in real learner order. All sixteen concepts now have additional authored instruction, but no cluster runtime or independent learner test has been performed. Continue other Cloud paths **within this school** before switching to Reliability or another school.


### Additional K8s source work (concept lessons 5–16)

Added directly to the authored lessons, without creating a separate generic overview: unschedulable Pod from impossible node selector; cluster DNS lookup while explicitly refusing to claim kind's default CNI enforces NetworkPolicy; a deliberately unbound PVC and correct boundary to backup/recovery; fake ConfigMap/Secret dry-run and environment-variable reload caveat; Running-but-not-Ready Pod with deliberately bad readiness probe; namespace-scoped read-only ServiceAccount/Role/RoleBinding and denied delete; OpenShift platform-only `oc` read-only introspection; illustrative OpenShift Route with TLS edge termination and SCC/Operator trade-offs.
