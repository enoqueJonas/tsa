## Distinct remediation, not the same generic appendix

**4 — Cisco Packet Tracer**: original 10 scenario labs preserved. Protocol teaching was already substantive for IOS modes, 802.1Q, STP/EtherChannel, OSPF and ACLs, but five advanced labs previously had lab-only steps without worked conceptual sections. `platform-builder-packet-tracer-worked.ts` now contributes two dedicated author sections per missing lab. Exact Python `ipaddress` VLSM program (60, 28, 12, 2 hosts from one /24) checks non-overlap and deliberately rejects a /27 for 60 hosts. This runs in CI, **not** in Cisco IOS; actual .pkt lab and device forwarding are still separately observable work.

**7 — Budget Homelab**: all 16 source readings had material coverage risk (most 35-minute bodies were two paragraphs), despite the detailed quality-layer practicals. `platform-builder-budget-homelab-worked.ts` attaches **32 topic-specific paragraphs/sections** to those exact readings. The source-executable capacity-refusal calculation gives one worked falsifiable engineering choice and explicitly identifies physical shared failure domains. The earlier recursive `normalizeEnterpriseBaseline` rewrote vendor/distro words; canonical Rocky Linux/WireGuard teaching is now authored directly.

**8 — Proxmox**: previously practical-only install, failure localization and host maintenance now each have a focused pre-lab reading with the actual management/VM/storage/host-to-guest boundaries and an explicit stop-before-destructive-action path.

**13 — Windows**: the WinRM/NTFS/AD/GPO/PowerShell concept readings already exist and should not be duplicated. The missing Linux–Windows interoperability prerequisite is added only to that lab: distinct SMB authentication/share/filesystem rights; AD DNS and TLS trust vs directory bind vs Keycloak/OIDC and Steward application role.

**14 — File/Directory**: NFS and SMB have different identities/permission models, as do directory protocol basics and AD-versus-OpenLDAP schema/federation. Two combined 180-minute lab contracts were split into four sequential focused lessons. The original NFS and LDAP lesson IDs remain; the two new exercises explicitly use synthetic data and require allowed/denied observations.

**Modules 5, 6, 9, 10, 11, 12, 15**: source provides mechanism, failure and safe evidence contracts already; replacing them with larger generic descriptions would lower quality. Retain and trace environment-specific execution separately. In particular, no amount of static source or GitHub hosted Ubuntu tests can establish Proxmox disk safety, live AD, remote firewall, actual NAS or an uncoached learner's competence.
